# Course notes

Before creating or editing any note, read:

1. `HANDOFF.md` — repository map, workflow, verification, hygiene.
2. `STYLE.md` — writing standard, device catalogue, style profiles
   (`mixed`, `rudin`, `zorich`, `abbott`, `tao`, `cambridge`, `legacy`, …).
   MATH 147 (`1a/math147/note-course`) uses `mixed`.
3. The target course's `handoff.md`, if it has one (it takes precedence).

Git on this machine: if `git` fails with an Xcode license message, prefix
commands with `DEVELOPER_DIR=/Library/Developer/CommandLineTools`.
